"""
目標
設計並實作一個「自動列印階段」腳本流程，用於列印指定 output 資料夾內的 .xlsx 與 .pdf 檔案。
此階段將由 PowerShell 腳本負責 orchestration；印表機選擇採「印表機名稱（print queue）分流」策略：
- 同一台實體印表機（RICOH MP C3503）在 Windows 上安裝兩次，形成兩個不同名稱的印表機佇列，但指向同一個 IP。
- 其中一個佇列為一般用途（PDF/A4/紙匣1），另一個佇列為特殊用途（Excel/A5/紙匣2）。
- 腳本僅以印表機名稱進行分流，不在程式內直接指定紙張尺寸或紙匣（紙張/紙匣由各佇列的 driver preset 鎖定）。

執行環境
- Windows 11
- PowerShell 5.1 為最低支援版本（允許在 PowerShell 7 執行，但不得要求僅 7 才能跑）
- 印表機：RICOH MP C3503
- 允許印表機名稱包含中文

輸入資料
- 指定目錄：<PROJECT_ROOT>\output\
- output 內包含：
  - Excel：.xlsx
  - PDF：.pdf

列印順序規則（必須遵守）
1. 以「檔案名稱字串排序」作為全體排序依據（以完整檔名排序，含副檔名，且以同一排序規則處理所有檔案）
2. 對排序後的結果逐一處理：
   - 若副檔名為 .xlsx：使用 Excel 專用印表機佇列列印（A5/紙匣2）
   - 若副檔名為 .pdf：使用 PDF 專用印表機佇列列印（A4/紙匣1）
3. 不允許重排、跳號、合併批次或先分組後排序

列印設定需求（由印表機佇列承擔）
一、Excel 檔案（.xlsx）
- 使用「Excel 專用印表機佇列」（預先在 Windows driver preset 設定：A5 + 第二紙匣）
- 每個 Excel 檔視為獨立列印任務
- 腳本不得依賴使用者當前預設印表機；必須顯式指定印表機名稱

二、PDF 檔案（.pdf）
- 使用「PDF 專用印表機佇列」（預先在 Windows driver preset 設定：A4 + 第一紙匣）
- 每個 PDF 檔視為獨立列印任務
- 腳本不得依賴使用者當前預設印表機；必須顯式指定印表機名稱

印表機名稱設定方式（可攜、可防呆）
- 腳本需使用「設定檔」保存兩個印表機名稱，避免硬編碼於腳本、避免每次手動輸入。
- 設定檔路徑：與腳本同目錄（例如：print-config.json）
- 設定檔內容至少包含：
  - PdfPrinterName：字串，PDF 專用印表機佇列名稱（可含中文）
  - ExcelPrinterName：字串，Excel 專用印表機佇列名稱（可含中文）

印表機選取流程（必須提供防呆）
1. 若設定檔不存在：
   - 腳本需進入「互動式選取流程」，讓使用者從本機已安裝的印表機清單中選取：
     - PdfPrinterName（PDF/A4/紙匣1）
     - ExcelPrinterName（Excel/A5/紙匣2）
   - 選取完成後必須寫入設定檔
2. 若設定檔存在：
   - 腳本需驗證設定檔內兩個印表機名稱在本機確實存在
   - 若任一不存在，必須重新進入互動式選取流程並更新設定檔
3. 互動式選取流程 UI 要求：
   - 優先使用 Out-GridView 提供可點選列表（若系統可用）
   - 若 Out-GridView 不可用，必須自動降級為「純文字編號選單」供使用者輸入序號選取
   - 不允許要求使用者手動完整輸入印表機名稱（除非作為最後備援，且需再次確認存在性）

錯誤處理要求（不中斷）
- 任一檔案列印失敗：
  - 必須記錄失敗檔名、使用的印表機名稱、錯誤原因
  - 不得中斷後續檔案的列印流程
- 全流程結束後需輸出摘要：
  - 成功列印數（按檔案數）
  - 失敗列印數（按檔案數）
  - 失敗檔案清單（含錯誤原因）

日誌與輸出
- 腳本需輸出一份 log（路徑固定、可預期），至少包含：
  - 執行時間
  - output 目錄路徑
  - 使用的 PdfPrinterName / ExcelPrinterName
  - 依排序順序列出的列印清單（檔名 + 類型 + 目標印表機）
  - 每個檔案的列印結果（OK/FAIL + 錯誤訊息）
- log 檔名格式可固定為 print.log（覆蓋或附加皆可，但需一致）

交付範圍
- 交付一個可直接執行的 PowerShell 腳本（例如：print-output.ps1）
- 不實作 GUI 應用程式
- 不要求安裝付費軟體（例如 PrintConductor）
- 不要求變更 phase1/phase2 的 Python 程式碼
- 不使用系統預設印表機作為列印目標（必須顯式指定印表機名稱）

最小驗收方式（必須提供）
1. 在 output 目錄放入至少 2 組檔案（各含 1 個 xlsx + 1 個 pdf），並確保檔名可排序
2. 第一次執行：
   - 觸發互動式印表機選取
   - 產生設定檔
3. 第二次執行：
   - 不再詢問印表機，直接讀取設定檔
4. 驗收點：
   - 列印順序與檔名排序一致（逐檔列印、不跳號）
   - .xlsx 走 Excel 專用佇列（A5/紙匣2）
   - .pdf 走 PDF 專用佇列（A4/紙匣1）
   - 任一檔案故意造成列印失敗時，後續仍繼續列印，且 log 有完整記錄
"""
