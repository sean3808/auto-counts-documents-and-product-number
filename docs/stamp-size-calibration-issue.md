# 印章尺寸校正問題報告

> 建立日期：2026-01-19
> 狀態：待解決

## 任務目標

將 TW111 和 TW113 供應商印章在 A4 紙張列印後達到以下實體尺寸：
- **寬度：4.5 cm**
- **高度：3.0 cm**

---

## 問題描述

### 初始狀況

| 印章 | 初始列印尺寸 | 目標尺寸 | 差距 |
|------|-------------|---------|------|
| TW111 | 4.0 × 2.7 cm | 4.5 × 3.0 cm | -12% |
| TW113 | 3.45 × 2.4 cm | 4.5 × 3.0 cm | -23% |

### 最新狀況（多次迭代後）

| 印章 | 當前列印尺寸 | 目標尺寸 | 差距 |
|------|-------------|---------|------|
| TW111 | 3.9 cm（寬） | 4.5 cm | -13% |
| TW113 | 4.0 cm（寬） | 4.5 cm | -11% |

**結論**：經過多次調整，尺寸仍未達標，且 TW111 從 4.0cm 反而變成 3.9cm。

## 已嘗試的解決方案

### 1. 程式碼：建立專用目標框配置

**檔案**：`src/doc_processor/stamper/purchase_order.py`

```python
# 目標框尺寸迭代歷程
# TW111: 130pt → 147pt → 179pt → 207pt → 239pt（當前）
# TW113: 130pt → 147pt → 195pt → 231pt → 260pt（當前）

STAMP_CONFIG_VENDOR_TW111 = StampConfig(

    target_width=239.0,

    x=382.7,
    y=612.6,
    target_width=260.0,
    target_height=173.0,

```

**結果**：目標框持續增大，但列印尺寸未按比例增加。

### 2. 圖片：旋轉校正

**問題**：TW111 原始圖片有逆時針傾斜，TW113 有輕微傾斜。

**處理**：
- TW111：順時針旋轉 8°
- TW113：順時針旋轉 3°

**結果**：圖片已校正為水平，但對列印尺寸影響有限。

### 3. 圖片：裁切空白區域

**問題**：圖片周圍可能有透明空白區域。

**處理**：使用 `PIL.Image.getbbox()` 裁切非透明區域。

**發現**：空白邊距僅 3-6 像素，佔比極小（約 1%），非主要原因。

### 4. 圖片：調整長寬比為 1.5:1

**目的**：確保圖片比例與目標尺寸比例一致（4.5:3.0 = 1.5:1）。

**處理**：
- TW111: 568×405 → 607×405 px
- TW113: 379×269 → 403×269 px

**結果**：比例已校正，但列印尺寸問題仍存在。

## 核心問題分析

### 問題 1：列印縮放比例不一致

| 印章 | 目標框 (pt) | 理論尺寸 (cm) | 實際列印 (cm) | 縮放率 |
|------|------------|--------------|--------------|--------|
| TW111 | 239×159 | 8.4×5.6 | 3.9×? | ~46% |
| TW113 | 260×173 | 9.2×6.1 | 4.0×? | ~43% |

**觀察**：
- 理論尺寸與實際列印差距極大（縮放率僅 43-46%）
- 這遠超過一般「適合頁面」的縮放（通常 92-95%）

### 問題 2：scale_image_to_fit 函數邏輯

**檔案**：`src/doc_processor/stamper/base.py`

```python
def scale_image_to_fit(orig_width, orig_height, target_width, target_height):
    if orig_width <= target_width and orig_height <= target_height:
        return orig_width, orig_height  # 不放大小圖
    # ... 等比例縮放到目標框內
```

**潛在問題**：
- 函數把圖片像素數當作原始尺寸（pt）
- 如果圖片像素 > 目標框，會被縮小
- 縮放後的實際 pt 尺寸可能不是預期值

### 問題 3：圖片像素與目標框的關係

| 印章 | 圖片像素 | 目標框 (pt) | 縮放計算 |
|------|---------|------------|---------|
| TW111 | 607×405 | 239×159 | scale = min(239/607, 159/405) = 0.39 |
| TW113 | 403×269 | 260×173 | scale = min(260/403, 173/269) = 0.64 |

**TW111 計算**：
- 縮放後尺寸 = 607×0.39 × 405×0.39 = 239×159 pt ✓

**TW113 計算**：
- 縮放後尺寸 = 403×0.64 × 269×0.64 = 260×173 pt ✓

理論上目標框應該被填滿，但實際列印結果不符。

### 問題 4：可能的根本原因

1. **列印設定**：
   - 是否確實使用「實際大小」而非「適合頁面」？
   - 印表機驅動程式是否有額外縮放？

2. **PDF 頁面尺寸**：
   - 原始 PDF 頁面可能不是標準 A4
   - 蓋章時的座標系統可能有偏差

3. **PyMuPDF (fitz) 行為**：
   - `insert_image` 的 rect 參數解釋方式
   - 圖片 DPI 對顯示尺寸的影響

4. **圖片內容 vs 邊界框**：
   - 用戶測量的是「印章圖案」的尺寸
   - 程式計算的是「圖片邊界框」的尺寸
   - 如果印章圖案未填滿圖片，會產生差距

### 方案 C：重新檢視圖片處理流程

### 方案 D：修改 scale_image_to_fit 邏輯

考慮修改為：不管圖片大小，都強制縮放到目標框尺寸。

```python
def scale_image_to_fit(orig_width, orig_height, target_width, target_height):
    # 移除「不放大」的限制，強制縮放到目標框
    width_ratio = target_width / orig_width
    height_ratio = target_height / orig_height
    scale = min(width_ratio, height_ratio)
    return orig_width * scale, orig_height * scale
```

### 解決方案不限

專家可使用任何方法解決問題，包括但不限於：

- 修改程式碼（蓋章邏輯、縮放計算）
- 調整圖片（尺寸、DPI、內容裁切）
- 修改 PDF 生成方式
- 調整列印設定或流程
- **在 PDF 中加入比例尺**：繪製一條 4.5cm 的參考線段，讓使用者列印後可直接對照，確認列印縮放是否正確
- **讓使用者手繪比例尺**：請使用者在列印後的紙張上先畫一條 4.5cm 的線段作為對照基準
- 其他創新方案

**唯一要求**：達成上述驗收條件，且不破壞既有功能。

### 診斷建議：比例尺對照法

在開始調整程式碼之前，建議先確認列印環境的縮放比例：

1. **方法 A：PDF 內建比例尺**
   - 在 PDF 中程式化繪製一條 127.56pt（= 4.5cm）的線段
   - 列印後測量該線段的實際長度
   - 如果不是 4.5cm，則問題出在列印環境，而非程式碼

2. **方法 B：手繪比例尺對照**
   - 請使用者用直尺在紙上畫一條 4.5cm 的線段
   - 將線段與列印出的印章比較
   - 可快速判斷印章與目標尺寸的差距

3. **方法 C：標準測試頁**
   - 建立一個測試用 PDF，包含已知尺寸的圖形（如 4.5×3.0cm 的矩形）
   - 列印後測量，確認列印環境的縮放比例
   - 根據實測縮放比例反推程式碼需要的補償值

**此診斷步驟可快速定位問題是在「程式碼」還是「列印環境」。**
