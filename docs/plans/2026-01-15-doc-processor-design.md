## 3. 單據對應關係

| 關係 | 比例 |
|------|------|
| 請購單 : 採購單 | 1 : 1 |
| 採購單 : 進貨單 | 1 : N |
| 採購單 : 進貨驗收單 | 1 : N |

## 4. Phase 1：PDF 批次合併

### 4.1 資料流

```
input/*.pdf
    │
    ▼
┌─────────────────────────────────────────────────┐
│  1. 掃描 input/ 所有 *.pdf（不遞迴）            │
│  2. 依檔名開頭判斷單別                          │
│  3. 依單別抽取關聯單號                          │
│  4. 從「採購單」建立請購單號→採購單號對照表     │
│  5. 依採購單號分組（請購單透過間接關聯）        │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  6. 對每組：                                    │
│     a. 排序：進貨單 > 進貨驗收單 > 採購單 > 請購單 │
│        （同類型依單據號碼升序）                 │
│     b. 從進貨驗收單抽取供商代號、供商簡稱       │
│     c. 合併 PDF 頁面                            │
│     d. 輸出檔案                                 │
└─────────────────────────────────────────────────┘
    │
    ▼
output/{採購單號}-{供商代號}-{供商簡稱}.pdf
```

### 4.2 單別判斷

依檔名開頭判斷（注意順序，先判斷較長的）：
1. `進貨驗收單` → 進貨驗收單
2. `進貨單` → 進貨單
3. `採購單` → 採購單
4. `請購單` → 請購單

### 4.3 關聯單號抽取 Regex

| 單別 | Regex | 說明 |
|------|-------|------|
| 進貨單 | `採購單號:\s?1[0-9]{12}` | 直接關聯 |
| 進貨驗收單 | `採購單號:\s?1[0-9]{12}` | 直接關聯 |
| 採購單 | `採購單號:\s?1[0-9]{12}` | 直接關聯 |
| 請購單 | `請購單號:\s?1A[0-9]{11}` | 間接關聯（透過採購單） |

### 4.4 供商資訊抽取

從**進貨驗收單**頁面抽取：
- 供商代號：`[A-Za-z]+\d+`（字母開頭 + 數字）
- 供商簡稱：`[\u4e00-\u9fff]+|[A-Za-z]+`（純中文或純英文，不含數字）

### 4.5 合併順序

```
進貨單（依單據號碼升序）
  → 進貨驗收單（依驗收單號升序）
    → 採購單
      → 請購單
```

## 5. Phase 2：Excel 明細生成

### 5.1 資料流

```
output/{採購單號}-{供商代號}-{供商簡稱}.pdf
    │
    ▼
┌─────────────────────────────────────────────────┐
│  1. 掃描 output/*.pdf                           │
│  2. 對每份 PDF：                                │
│     a. 提取全部文字                             │
│     b. 計算張數 = count("單據號碼")             │
│     c. 找到採購單頁（含「採購日期:」的頁面）    │
│     d. 計算支數 = 該頁中 ^\d{4}$ 獨立行的數量   │
│     e. 從檔名抽取採購單號                       │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  3. 讀取 template.xlsx                          │
│  4. 填入：                                      │
│     - B3 = {支數}                               │
│     - C3 = {張數}                               │
│  5. 另存新檔                                    │
└─────────────────────────────────────────────────┘
    │
    ▼
output/{採購單號}-單據明細.xlsx
```

### 5.2 欄位計算規則

| 欄位 | 計算方式 |
|------|----------|
| 張數 | 整份 PDF 中「單據號碼」文字出現的次數 |
| 支數 | 採購單頁中符合 `^\d{4}$`（獨立行、4 位數字）的行數 |
| 採購單號 | 從檔名抽取（`{採購單號}-{供商代號}-{供商簡稱}.pdf`） |

## 6. run.ps1 入口腳本

```powershell
# 職責：

## 8. 錯誤處理

### 原則
- 抓不到資訊即記錄失敗，**不做備援推測**
- 跳過失敗項目，繼續處理其他項目

### Phase 1 錯誤情況

| 情況 | 處理 |
|------|------|
| 找不到採購單號 | 跳過該檔案，記錄 log |
| 找不到供商代號/簡稱 | 跳過該組，記錄 log |
| 某組沒有進貨驗收單 | 無法取得供商資訊，跳過該組 |

### Phase 2 錯誤情況

| 情況 | 處理 |
|------|------|
| 找不到採購單頁 | 跳過該 PDF，記錄 log |
| 張數為 0 | 跳過該 PDF，記錄 log |
| 支數為 0 | 跳過該 PDF，記錄 log |

```

## 11. 硬性約束

- **不使用 OCR**：純 PDF 文字層解析
- **不遞迴子資料夾**
- **不設計備援規則**：抓不到資訊即記錄失敗，不做推測
- **不修改 input/**：原始檔案永遠保留
- 合併版執行時，Phase 1 必須完成後才進入 Phase 2
